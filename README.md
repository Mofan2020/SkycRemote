# SkycRemote

远程桌面，设备之间直连。

没有中继服务器。画面、按键、文件全在两台机器之间直接传。
Tracker 只登记地址和在线状态，不碰会话数据。

直连不成的用户用不了。这是项目的原则，不是还没做完的功能。

## 装

打开就是窗口。装好之后，命令行工具 `skycremote` 也在 PATH 上。

| 平台 | 文件 | 怎么装 |
|------|------|--------|
| macOS | `SkycRemote-<版本>.dmg` | 打开 DMG，把 SkycRemote 拖进「应用程序」 |
| Windows | `SkycRemote-Setup-<版本>-x64.exe` | 双击安装程序，跟着走完 |
| Linux | `skycremote-linux-x64.tar.gz` | 解压后运行里面的 `skycremote` |

macOS 上程序第一次启动时，会把命令行工具装进 `/usr/local/bin`；
那个目录写不进去就装到 `~/.local/bin`，并把它加进 shell 的配置里。

Windows 的安装程序会问装给谁：

- **只为我安装**：装在你自己账户下，不需要管理员密码。
- **为所有用户安装**：装进 Program Files，这台机器上的每个账户都能用。
  选这个会弹一次 Windows 的管理员权限提示，那是你自己的系统在问。

命令行工具装好之后就在 PATH 上，两种装法都是。

## 用

两端都要连到同一个 Tracker。Tracker 只登记地址，不转发任何会话内容：

```
skycremote tracker
```

被控端（被操作的那台）：

```
skycremote host --id 被控端的名字 --name 显示用的名字
```

控制端（你坐在前面的那台）：

```
skycremote control --id 被控端的名字
```

`control` 打开的就是窗口。直接双击程序，在窗口里点「共享」或者「控制」，也一样。

Tracker 地址在窗口的「设置」里改一次就够了，控制和共享都用那一个。设备 ID
和显示名字也在「设置」里，共享面板上只看不动。

设置存在程序自己的文件里，重启和重装都还在：

- macOS：`~/.config/skycremote/settings.json`
- Windows：`%APPDATA%\skycremote\settings.json`

共享的时候改码率和帧率，下一帧就生效，窗口会告诉你生效了没有。Tracker 和设备
ID 属于一次会话，要下次开始共享时才算数。

窗口右上角有个「日志」：程序做过什么都在里面，可以清掉。tracker 每次登记和
查找也在里面，「为什么连不上」看它就知道。

## Tracker 会自己起来

设置里的 Tracker 地址写的是本机（127.0.0.1）时，程序启动就会把本机的 tracker
带起来，端口上已经有人在跑就不重复起。设置页会告诉你另一台电脑该填哪个地址
（本机的局域网地址，127.0.0.1 只有本机能用）。

写的是别的机器的地址时，程序不另起 tracker，只记一行说明那是别人的。

命令行也能单独跑一个：

```
skycremote tracker
```

## 窗口关了以后

关掉窗口程序不会退出，共享和本机的 tracker 都继续跑。

- macOS：菜单栏里的小闪电。点它把窗口叫回来，右键菜单里能彻底退出。
- Windows：右下角通知区里的图标，同上。

想彻底停掉，窗口里的「设置 → 退出 SkycRemote」也行。Linux 上没有托盘图标，
关掉窗口还是照旧退出程序。

## 加密

两端先交换 X25519 公钥，算出只有这两台机器知道的共享密钥。被控端保存的是访问
口令散列出来的值，不是口令本身；控制端输入口令后算出同一个值，用它做一份证明
发给被控端。证明里带共享密钥，所以只有真正连到对端、并且知道口令的人才做得出来。

证明过了以后，会话密钥由共享密钥和这个散列一起派生（HKDF），控制消息和画面数据
都用 AES-256-GCM 加密。QUIC 的 TLS 1.3 保护传输。Tracker 看不到会话内容。

连接成功后两端会显示同一个六位数（安全码）。两边数字一样，说明中间没有人；不一样
就别往下用。

被控端没有设置访问口令时不允许远程控制。

## 协议

协议版本 2。

控制消息走可靠流，JSON 编码，每条消息前带 4 字节长度和 1 个标记（标记说明这条
消息有没有加密）。
画面走不可靠数据报，晚到的帧直接丢掉。整个数据报加密。
